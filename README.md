# 📍 PointGIS – WebGIS Analisis Spasial Data Titik  

PointGIS adalah aplikasi **WebGIS interaktif** berbasis **Leaflet.js** yang dirancang untuk menampilkan, mengeksplorasi, dan menganalisis **data spasial berbentuk titik**.  
Pengguna dapat mengunggah file **KML, KMZ, maupun Excel (XLS/XLSX)**, lalu sistem akan secara otomatis menampilkan titik di peta dan menyediakan berbagai analisis geospasial sederhana.  

---

## ✨ Fitur Utama
- 📂 **Upload Data**  
  - Mendukung format **KML, KMZ, dan Excel**.  
  - Data titik langsung divisualisasikan di peta.  

- 📊 **Dashboard Data**  
  - Statistik jumlah titik & atribut.  
  - Visualisasi interaktif dengan **Chart.js**.  
  - Daftar titik yang bisa diklik untuk zoom otomatis.  

- 🗺️ **Analisis Geospasial**  
  - **Jarak antar titik** → klik 2 titik untuk hitung jarak.  
  - **Buffer** → radius dari titik terpilih, menghitung jumlah titik di dalamnya.  
  - **Average Nearest Neighbor (ANN)** → analisis pola sebaran (klaster, acak, tersebar).  

- 🎨 **Antarmuka Modern**  
  - Desain clean dengan warna biru–ungu.  
  - Responsif di desktop & mobile.
